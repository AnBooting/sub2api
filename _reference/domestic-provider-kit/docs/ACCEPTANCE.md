# 接收方验收清单

- [ ] 创建和编辑分组都有国模选项；厂商图标、价格目录正确，保存后刷新不丢字段。
- [ ] 普通 OpenAI 组 domestic_provider 为空；切换平台不会残留不兼容厂商或账号选择。
- [ ] 添加账号显示 10 个厂商，选择后按规则填名称/Base URL，仍可手动编辑。
- [ ] API Key 被目标项目既有安全机制处理，页面/日志/错误响应不泄漏真实 Key。
- [ ] 编辑可回填厂商、URL、模型映射和协议模式；保存不会擦除其它 extra 字段。
- [ ] 账号分组候选只显示兼容厂商；绕过前端直接发请求也会拒绝不匹配绑定。
- [ ] 新建、编辑、复制、批量修改、通用 AccountService 更新均执行相同校验，失败无部分写入。
- [ ] 新数据库和已有数据库升级均成功，重复迁移处理符合项目规范，旧普通分组仍能读取。
- [ ] API Key 鉴权缓存读出的分组包含 domestic_provider，不会绕过价格命名空间。
- [ ] 价格目录 API 要求管理员身份；非法厂商、通配模型、负价、缺价、数据库错误正确拒绝。
- [ ] 未定价模型在请求上游前拒绝；输出 UI 是待定价而非零费用。
- [ ] 具体模型覆盖价、删除回退、缓存零价、百万 token 展示换算和有效用户倍率均正确。
- [ ] 如保留源站政策，峰谷时段、跨日边界和长上下文档位与测试预期一致。
- [ ] 真实测试账号能发普通和流式 Chat Completions 请求，base_url 不会重复拼接 /v1。
- [ ] 自动探测或 force_chat_completions 生效；仅支持 Chat Completions 的上游不会收到错误的 Responses 请求。
- [ ] 若开放 Responses 接入，验证转换、工具调用和流式中断；否则不要在 UI 宣称支持。
- [ ] 原普通 OpenAI/OAuth 和其它平台账号不受国模默认值与过滤条件影响。
- [ ] 分组/账号弹窗在桌面与手机宽度检查，无文字溢出，暗色主题图标可见。
- [ ] 目标前后端相关测试、类型检查、构建通过，并用本地测试账本核对实际扣费。
