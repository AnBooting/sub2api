# 给接手开发者 / Codex

任务：把本包里的国模分组、账号添加/编辑、厂商展示、价格目录与后端校验接入当前 Sub2API 二开项目。

先读目标项目 AGENTS.md、README.md 及本包 README.md、docs/INTEGRATION.md，然后运行只读预检。以当前项目架构和已有改动为准，逐项比较合并；不要把 reference 当成可覆盖的完整源码。

先检查是否已有 domestic_provider、价格解析器、Responses 自动探测与 Chat Completions 直转。列清实际缺失项后实现，不要重复建设或降低目标项目版本。新增 core 文件，按 MERGE-INDEX 合并共享逻辑，给迁移重新编号并生成 ent/wire。维持真实 platform=openai，补齐创建/编辑/批量入口的后端厂商绑定检查。

核对本包的两项源版兼容说明：Anthropic 与 SQL 约束范围不同；创建弹窗的国模提前返回分支未持久化协议模式。根据目标现有能力适配，只在明确国模账号范围改变默认协议。

价格目录是源站快照，采用国内标价数字当站内 USD 的政策。先阅读目标项目经营配置，决定如何保持目标的计价约定，并让前端展示、后端计费及测试一致。不得让缺价模型按零价或普通 GPT 兜底价通行。

完成 ACCEPTANCE 清单和目标项目构建，给出实际修改文件、迁移编号、测试结果与剩余兼容问题。不要迁移支付、画布、智商检测、监控或生产凭据。未经目标项目所有者指示不要部署到生产。
