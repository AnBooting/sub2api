# Sub2API 国模分组与账号功能移植包

提取日期：2026-09-20。来源：AIportX 主站 1.0.65 已核对的发布源码快照。

本包用于把「国模分组 + 国模账号添加/编辑 + 厂商图标 + 价格目录 + 绑定校验与计费接入」合并到另一套 Sub2API 二开项目。它是源码移植包，不是独立应用，也不是能覆盖任意 Sub2 版本的一键升级包。

## 包含什么

- 国模入口和 10 个厂商选项：DeepSeek、Qwen、豆包、Kimi、智谱、MiniMax、百川、零一万物、阶跃星辰、自定义。
- 分组创建/编辑的厂商选择、图标、模型输入/输出/缓存价格、峰谷提示与待定价状态。
- 账号创建/编辑的厂商选择、预设 Base URL、API Key、模型映射、分组筛选和厂商信息回显。
- 后端字段、数据库迁移、分组与账号匹配校验、价格目录管理 API、计费解析及请求前价格校验。
- 原项目相关测试、合并定位索引、只读预检脚本、接口数据示例。

## 从这里开始

1. 阅读 [移植步骤](docs/INTEGRATION.md)，特别是价格口径和协议兼容说明。
2. 在朋友的项目目录运行 `node /解压路径/tools/preflight.mjs .`，查看文件冲突和依赖提示；脚本不会修改项目。
3. 按 [合并索引](docs/MERGE-INDEX.md) 合并共享文件里的相关代码。
4. 按 [验收清单](docs/ACCEPTANCE.md) 验证保存、调用、计费和普通 OpenAI 回归。

也可把 [给接手开发者或 Codex 的任务说明](docs/HANDOFF.md) 交给朋友的开发者。

## 目录

| 路径 | 用途 |
| --- | --- |
| `core/` | 7 个国模专用文件；目标不存在时可按原相对路径新增，存在时比较合并 |
| `reference/shared/` | 弹窗、页面、DTO、仓储、路由、计费等共享文件的完整参考；禁止整目录覆盖 |
| `reference/protocol/` | OpenAI 兼容上游协议选择与转发参考，按目标版本需要合并 |
| `reference/test-support/` | 测试配置、共享测试辅助函数参考 |
| `migrations/` | 原始 196、197、198 迁移；在目标项目重新编号 |
| `tests/` | 国模功能测试；须与目标项目现有测试辅助代码对接 |
| `examples/` | 不含真实凭证的请求体示例 |
| `docs/` | 合并指南、定位摘录、验收与验证记录 |
| `licenses/` | 原项目 LGPL-3.0、图标 MIT 许可及来源说明 |
| `SOURCE-MANIFEST.json` | 每个提取源文件的类别、大小、SHA-256 |
| `SHA256SUMS` | 整个交付包文件校验清单 |

## 交付边界

只提取源代码与文档。包内没有生产账号、真实 API Key、环境变量、数据库备份、SSH 信息、部署配置或主站运行数据。共享参考文件含有其它功能的上下文，是为了看清函数边界，不代表需要移植这些功能。画布、支付、账号智商检测、渠道监控不在本次移植范围。

尚未取得接收方源码，因此没有声称在对方版本编译通过。源版本的测试结果见 [验证记录](docs/VERIFICATION.md)。
