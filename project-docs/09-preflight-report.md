1. **7 个 core 文件上游全无** → 国模功能是真实净增量，不是重复建设。
2. **47 个共享文件全部有差异**，且差异远大于国模本身（合计 +12,798 / -5,136 行），
   说明这些差异里**混杂了大量上游演进**（支付、渠道监控、画布、Codex 等）。
