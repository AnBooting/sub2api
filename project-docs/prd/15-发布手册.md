# 发布手册

版本：0.1｜日期：2026-10-10。部署见 [../05-deploy-docker.md](../05-deploy-docker.md)，运维见 [../08-runbook.md](../08-runbook.md)。生产服务器信息尚未提供，命令中的占位符在发布前替换。

## 1. 发布前检查

| 项 | 判定 |
|---|---|
| 测试 | [14 测试计划](14-测试计划.md) 全部通过，记录齐全 |
| 外模缺价盘点 | 按线上 WARN 日志列出缺价模型并补价；未补的模型发布后会被拒绝，需站长确认清单 |
| 国模价格源 | `pricing.native_cny_enabled=true`，首次同步成功，状态 ok |
| DeepSeek 节假日 | `deepseek.holidays` 已录入当年法定节假日 |
| 迁移 | 脱敏数据副本上升级 + 回滚各成功一次 |
| 对账 | 副本升级前后余额/已用额度/消费明细导出 diff 为 0 |
| 云猫 | Q-4 资料齐全且测试店铺验证通过后才开启商品中心 |

## 2. 步骤

1. 公告维护窗口（如需停机）。
2. 备份：`pg_dump -Fc -f backup_<日期>.dump <数据库>`；记录当前镜像 tag，备份 .env。
3. 导出余额与消费基线并留档。
4. `docker compose pull && docker compose up -d`；迁移随启动执行。
5. 健康检查：`GET /health` 返回 200；管理端价格同步状态为 ok。
6. 冒烟：国模、外模、DeepSeek 各一次请求，检查锁价快照与实际组；缺价模型返回 `pricing_unavailable`。
7. 再导出余额基线，与第 3 步 diff 为 0。
8. 观察 24 小时：错误率、`pricing_unavailable` 数量、同步告警。

## 3. 回滚

触发：对账 diff 不为 0、核心路由错误率明显上升、出现重复扣费。

1. `docker compose down`，镜像 tag 改回发布前版本，恢复原 .env。
2. 本期迁移只新增表和字段时旧版本可直接启动；含不兼容变更时先 `pg_restore --clean -d <数据库> backup_<日期>.dump`（会丢失发布后写入的数据，需评估）。
3. 启动后重复第 2 节第 5、7 步。

## 4. 按模块关闭

| 模块 | 方式 |
|---|---|
| 国模 CNY 价格 | `pricing.native_cny_enabled=false` |
| 调度策略 | `scheduling.strategy=balanced`（默认） |
| 商品中心 | 不配置云猫凭据即不开放 |
| 视频新计价 | 不配置模型×分组视频价即拒绝新视频请求，需提前告知 |
