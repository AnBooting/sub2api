# 接口文档（本期涉及接口）

版本：0.1｜日期：2026-10-10｜状态：草案。「现有」= develop 路由中已有（backend/internal/server/routes），「新增」= 本期计划，路径为建议值，落地后以代码为准回写。错误码见 [11 共享契约](11-共享契约.md) C-7。

## 1. 网关（API Key 鉴权）

| 方法 路径 | 状态 | 本期变化 |
|---|---|---|
| POST /v1/messages、/v1/chat/completions、/v1/responses、/v1beta/models/*、/v1/embeddings | 现有 | 取价时刻 = 请求发起时刻；缺价返回 `pricing_unavailable`（503，国模外模一致）；按 Key 分组链换号/换组，全部不可用返回 `no_available_group`；超时无法确认执行返回 `upstream_uncertain` |
| POST /v1/images/generations、/edits、/async；/v1/images/batches* | 现有 | 按图片迁移清单逐条比对（Q-7），差异只补适配 |
| POST /v1/videos、/v1/videos/generations 等；GET /v1/videos/:request_id | 现有 | 提交前校验模型×分组视频价，缺价拒绝并去掉图片价回落；查询走本地任务表并校验归属，非本人 404 |
| GET /v1/usage、/v1/sub2api/billing | 现有 | 金额单位为 Credit |

## 2. 用户端（JWT）

| 方法 路径 | 状态 | 本期变化 |
|---|---|---|
| GET/POST/PUT /api/v1/keys、/keys/:id | 现有 | 增加 `groups: [{group_id, role: normal或ha, position}]`；`group_id` 保留，等于 position=0 的普通组；ha 只能本人开启 |
| GET /api/v1/groups/available、/groups/rates | 现有 | 增加可作兜底的组、适用模型、当前倍率 |
| GET /api/v1/usage、/usage/:id | 现有 | 增加 `served_group`、`failover`、锁价快照（不含账号） |
| POST /api/v1/redeem | 现有 | 不变，卡密兑换入口 |
| GET /api/v1/shop/products | 新增 | 商品快照 + `purchasable`（同步异常为 false） |
| POST /api/v1/shop/orders | 新增 | 下单；同步异常返回 `product_sync_unavailable`；幂等键 = 客户端请求 ID |
| GET /api/v1/shop/orders、/shop/orders/:id | 新增 | 状态 pending / paid / delivery_pending / delivered；卡密仅本人可见 |

## 3. 管理端

| 方法 路径 | 状态 | 本期变化 |
|---|---|---|
| GET/PUT /api/v1/admin/channels/pricing/settings | 现有 | 增加同步周期（覆盖 `pricing.update_interval_hours`）与各源同步状态（C-2） |
| POST /api/v1/admin/channels/pricing/refresh | 现有 | 手动同步；校验失败保留 LKGP |
| GET/PUT /api/v1/admin/settings | 现有 | 新增 `scheduling.strategy`、`deepseek.holidays` |
| GET/PUT /api/v1/admin/groups/:id | 现有 | 新增 `scheduling_strategy`（inherit/stable/balanced/latency）、`ha_enabled`、兜底适用模型 |
| GET/PUT /api/v1/admin/video-pricing | 新增 | 模型×分组 → `{mode, base_credit_price}`；两种模式并存返回 `video_mode_conflict` |
| GET /api/v1/admin/shop/sync-status、POST /api/v1/admin/shop/sync | 新增 | 商品同步状态与手动同步 |
| GET /api/v1/admin/usage | 现有 | 增加 `requested_group_id`、`attempt_count`，按 request_id 追溯 |
