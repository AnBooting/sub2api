# PRD 文档集

正式开发评审基线。读法：先 00，再看要做的 PRD，开发时对照 12 号对应 TS 节。

| 文件 | 作用 | 谁改 |
|---|---|---|
| [00 需求优先级与实施路线](00-需求优先级与实施路线.md) | 冻结业务基线、优先级、阶段 | 产品经理 |
| [01](01-PRD-01-统一模型价格获取与Credit计价.md)～[06](06-PRD-06-图片视频中转与多维计费能力.md) | 六个需求的业务规则与验收 | 产品经理 |
| [10 共享规范](10-共享规范.md) | 术语、计费/时间/幂等/安全规则、质量门 | 研发，评审后冻结 |
| [11 共享契约](11-共享契约.md) | 跨 PRD 的数据结构、错误码、配置键 | 研发，改动先评审 |
| [12 技术规格](12-技术规格.md) | TS-01～06：现状锚点、改动点、测试、阻塞 | 研发，滚动修订 |
| [13 接口文档](13-接口文档.md) | 本期涉及的现有/新增接口 | 研发 |
| [14 测试计划](14-测试计划.md) | 分层、重点用例、回归 | 研发/测试 |
| [15 发布手册](15-发布手册.md) | 发布前检查、步骤、回滚 | 研发/运维 |
| [20 执行计划](20-执行计划.md) | 当前阶段任务与状态，非权威 | 研发，随时改 |
| [90 评审问题与冲突](90-评审问题与冲突.md) | PRD 与源码的冲突、待决问题 | 双方，决策后关闭 |

优先级：PRD 业务口径 > 11 契约 > 12 TS > 20 计划。下层与上层冲突时改下层，或在 90 号登记。
