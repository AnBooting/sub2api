## 三、协作约定

1. **先文档后代码**：PRD 与规格先评审通过，再写代码。
2. **一条需求一个分支**：`feat/REQ-XXX-<简述>`。
3. **规格里的每个「影响文件」都是 write scope**：多人并行时按此划分，互不重叠。
4. **验收标准必须可执行**：写不出验证命令的标准不算数。
5. **计费改动必须给数值对比**。
6. **未确认的事写「未确认」**，不猜。
