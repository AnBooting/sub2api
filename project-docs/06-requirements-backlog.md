## 问卷回收结论（2026-10-10）

> 原件：团队填写版 `E:\Downloads\16-requirements-questionnaire-26.10.08-W.md`，以下为与负责人逐条确认后的结论，**覆盖上表中冲突的旧决策**。

| 需求 | 结论 | 仍缺 |
|---|---|---|
| REQ-009 调度 | DeepSeek 42 个 API Key，现象「部分账号未被路由、部分压力过大」，与 concurrency/load_factor 分裂根因吻合；实值未知 → 以诊断面板取证。上游无官方 RPM/TPM 限制。**429 冷却改为 15 秒后线性恢复，参数后台可调**（取代 5 分钟）。OpenAI 为 API Key + OAuth 混合 | 线上实值（诊断面板）；B3 生效延迟、实例数 |
| REQ-010 云猫 | 云猫**只有支付回调**，无下单/查单 API。**一期：iframe 嵌入云猫购买页 + 回调到账**（A7 确认可嵌入）；买家对不上站内用户的订单只发兑换码，用户自行兑换。**二期：用自己的店铺下小额测试单抓包，评估非公开下单接口，可行且负责人确认风险（违反条款/封店、改版失效、风控）后再封装成自有页面**。商品做成**后台可配置**（名称、价格、权益），价格 1–198 元，类型=额度/订阅/并发，无限购，运营自录。历史订单约 300 条（2026-09～10），可导出 CSV，部分对不上用户，卡密不过期。退款：回调无法退款，**一律人工处理**。展示位置：现有充值页分标签页 | 回调文档（字段、签名、来源 IP）；用户标识如何传入 iframe |
| REQ-011 兜底 | **改为：管理员配置「可选兜底分组池」+ 全局默认链；用户可在 Key 上从池里选择并排序，不选则用全局默认**。Key 未选分组时的默认分组：团队写「default 1X，可用 ds、glm、部分 gpt/claude」，具体分组名**按线上实际数据决定** | 线上分组清单 |

| REQ-015（新）画布前端 | 图片/视频需要前端画布，基于 GitHub 开源方案，**排在 REQ-012 后端完成之后**；候选项目由我调研推荐 2–3 个 | 选型评审 |
