### 2.3 合并期发现并修掉的三处真实问题

1. **护栏缺口：上游新增的 Gemini models 端点绕过请求发送预算**
   `backend/internal/service/gemini_models_endpoints.go`（上游新增）的 `doGeminiModelsGET` 直接调 `s.httpUpstream.Do`，不计入单逻辑请求的发送预算。已改为经 `sendUpstreamWithBudget`，并把 `TestRequestAttemptBudgetHookWiringIsComplete` 从"按文件数调用次数"改成**按行为反向扫描全包**（新增 `TestRequestAttemptBudgetEveryUpstreamSendIsGated`），新增发送点未登记豁免会立刻变红。变异验证：改回直发 → 3 条断言同时转红。
2. **护栏用例失效：按文件计数太脆**
   上游把 `ForwardAIStudioGET` 搬到新文件后，旧断言"某文件里必须出现 3 次"变成假红；同时它也抓不到"新文件里新增一个绕过预算的发送点"。已按上条重写。
3. **本地化遗漏（上游新护栏抓到的我们的问题）**
   上游新增的 `TestUserFacingGroupDTOsAreLocalized` 扫描用户侧 handler，发现我们 PRD 的**高可用兜底分组响应**（`api_key_handler.go` 的 `writeHAEnablementResponse`）返回的 api_key / group DTO 没有走 `.Localized(Accept-Language)` → 分组名与描述不随请求语言变化。已补上本地化，护栏恢复通过。

### 2.4 语义决策项（需要产品/业务确认，见 3.6 的 D1–D7）
