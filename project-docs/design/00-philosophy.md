# 00 · 设计哲学（v2）：暖纸上的编辑体

> 状态：**冻结** · 唯一事实源。v1「冷石墨配线图」已废弃 —— 太冷、太均质，缺审美浓度。
> 本版保留 v1 的结构纪律（痕量线、切角、读数册、克制动效），换掉气质：**暖纸、衬线、编辑体的呼吸感**，方向对齐 Claude 那种「安静但有教养」的审美。

## 一、这是什么界面

一套聚合网关的控制台。它每天被读数、对账、排查 —— 所以它首先得**耐看**，其次才是「显得专业」。

v1 的错误是把「工程感」做成了「冷感」：冷灰纸 + 冷蓝信号 + 全无衬线，一眼望去像监控面板，谁都不想在里面待着。
v2 的判断是：**专业不等于冷**。一本做得很好的技术手册、一份排版精良的对账单，既严谨又好看 —— 那才是这套界面该有的样子。

## 二、气质：暖纸上的编辑体

- **纸是暖石灰**，不是冷灰也不是奶油米色（后者是 AI 生成的常见套路）。它像一本用了很久的手册：微暖、不刺眼、大面积留白不显空洞。
- **墨是带暖的深褐**，不是纯黑。和纸同源，所以压得住；纯黑压在暖纸上会有「贴上去」的廉价感。
- **标题用衬线**（Newsreader，带光学尺寸轴）。这是整个界面气质的来源：大字号时衬线的粗细对比会呼吸，小字号时它退回去不抢戏。
- **正文与操作保持无衬线**（Archivo，宽度轴）。衬线负责气质，无衬线负责精确 —— 读数、按钮、表格数值都不该有衬线的柔软。
- **信号是克莱因钴蓝**：唯一「通电」的颜色，压在暖纸上对比强烈但不刺眼。状态用铁锈红（断线）、赭石金（测量）、苔绿（通路）—— 全部暖调，和纸同族。

## 三、形

- 转角 3px 基准，最大 6px。不是被磨圆的糖块，也不是锐利的工业边 —— 是纸被裁切的厚度。
- 层级靠 **1px 痕量线 + 留白 + 一层极轻的暖影**（box-shadow: 0 1px 0，像纸叠在纸上），不是投影。
- 只有真正浮起的层（弹层、抽屉、悬浮卡）才用 shadow-float，且阴影是暖褐不是纯黑。
- 表格是「读数册」：等宽数字、右对齐、冻结表头。行高比 v1 更松（padding 0.625rem），因为它要被人长时间盯着看。

## 四、字（v2 的核心变化）

**两族分工，这是审美浓度的关键**

| 角色 | 字族 | 用在哪 |
|---|---|---|
| 展示 / 标题 | **Newsreader**（衬线，光学尺寸轴） | h1/h2、页面图签标题、大读数、品牌名、首页 hero、引文 |
| 界面 / 正文 | **Archivo**（无衬线，宽度轴） | 按钮、表格、表单、标签、正文、h3/h4 |
| 读数 | **Archivo** + tabular-nums | 表格数值、余额、时间、百分比 |

- 标题字号阶：display-sm 1.375rem → display-md 1.875rem → display-lg 2.5rem → display-xl 3.5rem，行高 1.02–1.25，字距 -0.028em（衬线必须负字距，否则松散）。
- **衬线不超过两处同屏**：一个页面里衬线只用在「读者第一眼读的那一句」和「最大的那个读数」。到处都是衬线会变成婚庆请柬。
- 中文回落：Songti SC / Source Han Serif SC（衬线）、PingFang SC（无衬线）。
- 仍然禁止：标题里单词变色/斜体强调、全大写标签、每段上方的小字眉标。

**新增的排版件**（都在 style.css，直接用）

.lead 引导段 · .drop-cap 首字下沉（只用于叙述型页面）· .readout-display 衬线大读数 · .pull-quote 引文 · .rule-soft 细分割 · .lift 浮层 · .panel-inset 凹陷面

## 五、动

- 只有**一个**编排过的瞬间：页面进入时痕量线从左到右画出（620ms，ease-settle 慢收），标题同时做一次微小的字距收束（type-settle）。两者同时发生，算一个瞬间。
- 交互动效只回答人的动作，≤240ms，且必须能在减少动效模式下退化为瞬时。
- 禁止：卡片逐张淡入上滑、hover 发光/位移/缩放、滚动视差、无限循环装饰。

## 六、克制

把胆量花在**衬线标题**这一处。其他一切安静到近乎冷淡：不加装饰图形，不加光斑，不加渐变，不加图标墙。

Chanel 的话仍然有效：出门前照镜子，摘掉一件配饰。

## 七、移动端不是降级版

同一张纸、同一族衬线、同一根线。手机上只是**编排**改变（导航收进抽屉 + 底部工具坞、表格横向滚动、弹层从底部升起）。衬线标题在手机上仍然保留 —— 那是气质，不是装饰，不能因为屏幕小就删掉。
